# BM2 Sipware ☕✨

**BM2 Sipware** is a high-performance e-commerce platform for original art mugs and personalized custom-printed drinkware, built with **Next.js 14 App Router**, **MongoDB**, **Razorpay**, **Qikink Print-on-Demand Fulfillment**, and **ImageKit.io** real-time image processing.

---

## Features

- **Curated & Original Catalog**: Browse unique art mugs, ceramic cups, enamel mugs, and steel bottles with HD sublimation print guarantees.
- **ImageKit.io Custom Print Studio**: Upload custom artwork or photos, apply real-time ImageKit transformations (rotation, crop/fit modes, grayscale, sepia, high-contrast, sharpen), and preview custom designs instantly on drinkware mockups.
- **Razorpay & COD Checkout**: Seamless prepaid payment integration via Razorpay along with Cash on Delivery (COD) options.
- **Automated Qikink Fulfillment**: Direct API integration to sync orders with Qikink for automated printing and dispatch, complete with tracking links and webhook status handling.
- **Admin Dashboard**: Manage orders, filter by online/COD/success/failure, export orders to CSV, add store coupons, and manage products with live mockup uploads.
- **Email Notifications**: Automated order confirmation emails powered by **Resend**.

---

## Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Modern CSS with CSS Modules & Responsive Design
- **Database**: MongoDB (with local mock fallbacks)
- **Image Optimization & Storage**: **ImageKit.io SDK** (`@imagekit/next`, `@imagekit/nodejs`)
- **Payments**: Razorpay
- **Fulfillment**: Qikink API
- **Email**: Resend API
